# أورد على السريع ⚡🛵

تطبيق أندرويد بيوصّل أصحاب المشاريع اللي شغالين أونلاين بأقرب كابتن توصيل.

## صاحب المشروع
- يحدد مكان مشروعه على الخريطة (GPS أو دوسة على الخريطة)
- يشوف الكباتن الأونلاين حواليه مترتبين بالأقرب، ومعاهم التقييم والمستوى
- أوردر جديد: مكان العميل (خريطة / موقعي / لصق لينك لوكيشن من واتساب)، بيانات العميل، **قيمة التوصيلة إجباري**، قيمة الأوردر، تحصيل كاش
- تتبع لحظي للكابتن على الخريطة + الوقت المتوقع + مراحل الأوردر
- كود تسليم سري يتبعت للعميل على واتساب مع مكان الكابتن
- لو الكابتن رفض يختار كابتن تاني، أو يلغي
- تقييم الكابتن بالنجوم + ملاحظات، وكباتن مفضلين
- رسايل الإدارة

## الكابتن
- تسجيل + صورة بروفايل + رفع البطاقة (وش وضهر) للتوثيق
- أونلاين/أوفلاين، والموقع بيتبعت لحظي (حتى وهو فاتح جوجل ماب)
- إشعار واهتزاز لما يجيله أوردر، قبول/رفض
- «امشي باللوكيشن» بيفتح جوجل ماب على المحل ثم العميل
- مراحل: استلمت ← في الطريق ← وصلت ← التسليم بكود العميل
- المحفظة: العمولة المستحقة (5%)، أرقام انستا باي وفودافون كاش، رفع سكرين التحويل
- لو العمولة المتأخرة عدّت الحد مايقدرش يبقى أونلاين
- نقط ومستويات (برونزي/فضي/ذهبي/ماسي) وهدايا يستبدلها، وترتيب أحسن الكباتن
- زرار طوارئ SOS
